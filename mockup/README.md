# Ảnh chụp bản mẫu giao diện app VN-EML

Bảng màu đã chốt: **"Đồng và trời" với màu cam chính #E8590C**. Chi tiết màu nằm trong `docs/bang-mau.md`.

Bản mẫu bấm thử: https://claude.ai/artifact/6h4qbgLCTB64geYXKWBgxZ. Mỗi khung có nút Tweaks để chuyển giữa chế độ sáng và tối.

| Thư mục | Nội dung |
|---|---|
| `che-do-sang/` | 23 ảnh chế độ sáng |
| `che-do-toi/` | 23 ảnh chế độ tối, tên file giống hệt chế độ sáng |
| `linh-vat/` | `chim-lac-chinh-thuc.png` (hình linh vật dùng trong app) và `bang-mau-linh-vat.png` (bảng màu gửi kèm khi sinh hoặc vẽ lại linh vật). Xem `docs/linh-vat.md` |
